# Forecast desk

## Register

product

## Users

The team reviews and demonstrates the weather blending project to competition judges using screenshots and a recorded demo. Forecast reviewers inspect model choices, uncertainty and verification evidence.

## Product Purpose

Combine actual IFS, GFS and AIFS forecasts through learned weighting and baseline comparison, then explain the selected forecast and its supporting evidence. Make the value understandable at a glance without obscuring data limitations.

## Brand Personality

Clear, practical, evidence led. Preserve the existing green dashboard identity and familiar controls; emphasize the working system rather than event branding.

## Anti-references

The user rejects generic AI-looking callout boxes, tiny important text, overlapping map labels, excessive jargon and prototype identifiers. Avoid decorative effects and unearned forecasting claims.

## Design Principles

- Show the three inputs, selected output and decision evidence together.
- Distinguish the selected method from competing router candidates.
- Prioritize readable screenshots and an easy demonstration flow.
- Preserve genuine missing data, publication gates and the ERA5 reference label.
- Keep controls, IST formatting and existing navigation working.

## Accessibility & Inclusion

Preserve keyboard focus, semantic controls, reduced motion and readable contrast. Describe source contributions in text as well as color. Keep responsive layouts and local script checks; the user requests no browser control.
